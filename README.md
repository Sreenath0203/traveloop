# 🌍 Traveloop

A full-stack travel planning application that helps users organize trips, create itineraries, track budgets, and receive smart travel recommendations.

---

## ✨ Features

- 🔐 Secure User Authentication
- ✈️ Create & Manage Trips
- 🗓️ Day-wise Itinerary Planner
- 📍 Destination Planning
- 💰 Budget Tracking & Analytics
- 📊 Expense Visualization
- 🤖 AI Travel Recommendations
- 📱 Responsive User Interface

---

## 🛠 Tech Stack

### Frontend
- React.js
- Tailwind CSS
- React Router
- Axios
- Recharts

### Backend
- Node.js
- Express.js
- JWT Authentication
- bcryptjs
- Express Validator
- Multer

### Database
- MySQL

## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/Sreenath0203/traveloop.git
cd traveloop
```

---

## 📦 Install Dependencies

### Backend

```bash
cd server
npm install
```

### Frontend

```bash
cd ../client
npm install
```

---

## ⚙ Environment Variables

Create a `.env` file inside the **server** folder.

```env
PORT=5000
JWT_SECRET=your_secret_key
```

Update the database credentials in **db.js**.

---

## 🗄 Database

Create a MySQL database.

```sql
CREATE DATABASE traveloop;
```

Import your SQL file (if available) into the database.

---

## ▶ Run the Application

### Start Backend

```bash
cd server
npm start
```

Backend runs on:

```
http://localhost:5000
```

---

### Start Frontend

```bash
cd client
npm start
```

Frontend runs on:

```
http://localhost:3000
```
